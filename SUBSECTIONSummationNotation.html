    Subsection 1.2.2 Summation Notation

    Recall that Leibniz used a stylized Latin S to represent a sum of differentials in his notation \(\int{y \dx{x}}\text{.}\) In [cross-reference to target(s) "SECTIONThinkingAboutIntegration" missing or not unique] we introduced the Greek letter sigma \(\Sigma\) to represent a sum of finite quantities. Later when introducing definite integrals, we made this more precise with the notation \(\int^b_{x=a}{y \dx{x}}\) to indicate summing differentials for all real numbers between \(x=a\) and \(x=b\text{.}\) With this in mind, we will use the following notation.
    🔗
    Let \(a\) and \(b\) be integers with \(a\le b\text{.}\) Then
    \begin{equation*} \sum^b_{n=a}{y(n)}=y\left(a\right)+y\left(a+1\right)+y\left(a+2\right)+\dots +y(b) \end{equation*}
    🔗
    Since we will eventually be applying our notation to power series, it is customary to write \(y(n)\) as \(y_n\) and to write
    🔗
    \begin{equation*} \sum^b_{n=a}{y_n}=y_a+y_{a+1}+y_{a+2}+\dots +y_b \end{equation*}
    We can also write
    \begin{equation*} \sum^{\infty }_{n=a}{y_a}=y_a+y_{a+1}+y_{a+2}+\dots \end{equation*}
    🔗

    Example 1.2.2.0.3.

    (a)

    \(\displaystyle\sum^1_{n=1}{n}=1 \sum^2_{n=1}{n}=1+2 \sum^8_{n=3}{n^2}=3^2+4^2+5^2+6^2+7^2+8^2 \)
    🔗
    🔗

    (b)

    \(\displaystyle\sum^{\infty }_{n=0} {{\left(\frac{1}{2}\right)}^n} = {\left(\frac{1}{2}\right)}^0+ {\left(\frac{1}{2}\right)}^1+ {\left(\frac{1}{2}\right)}^2+\dots \)

    Problem 1.2.2.0.7. Sum of the Reciprocals of the Triangular Numbers.

    Back when we were talking about Leibniz and the Fundamental Theorem of Calculus, we mentioned that Huygens gave Leibniz the problem of summing the reciprocals of a all of the triangular numbers. That is, he had to sum
    \begin{equation} \frac{1}{1}+\frac{1}{1+2}+\frac{1}{1+2+3}+\dots \tag{1.2.1} \end{equation}
    🔗

    (a)

    Use summation notation to express formula (1.2.1).
    🔗
    🔗

    (b)

    The numbers \(T_n=1+2+3+\dots +n\) is called the \(n\text{th}\) triangular number because they represent the number of dots arranged in a triangular pattern.
    🔗
    🔗

    (c)

    We also mentioned the formula
    \begin{equation*} T_n=\frac{n\left(n+1\right)}{2} \end{equation*}
    There are different ways, both geometric and algebraic, to show this formula. We will use summation notation to obtain it.
    🔗
    Show that
    \begin{equation*} \sum^n_{j=1}{j}=T_n=\sum^n_{j=1}{(n+1-j)} \end{equation*}
    and use this to show that
    🔗
    \begin{equation*} 2T_n=\sum^n_{j=1}{(n+1)} \end{equation*}
    to obtain the formula for \(T_n\text{.}\)
    🔗
    🔗
    🔗
    In the previous problem, it was easier to see that \(T_n=\sum^n_{j=1}{(n+1-j)}\) by writing out a few terms and noticing the pattern. Summation notation is very precise and does not rely on the reader noticing the correct pattern, but it can also look more complicated, especially for those who are unfamiliar with it. Using it or not using it are both correct (provided you demonstrate a definite pattern if you expand it out). Whether you use it or not will depend on the situation as demonstrated above. When you do the next problem, try and decide if it is better to use summation notation or to expand the sum in each instance.
    🔗

    Problem 1.2.2.0.10.

    Earlier, we obtained
    \begin{equation*} \int^{\frac{4}{3}}_{z=\frac{2}{3}}{e^{-{\frac{1}{2}z}^2}\dx{z}}=\left(\frac{4}{3}-\frac{2}{3}\right)-\frac{1}{1!\cdot 2\cdot 3}\left({\left(\frac{4}{3}\right)}^3-{\left(\frac{2}{3}\right)}^3\right)+\frac{1}{2!\cdot 2^2\cdot 5}\left({\left(\frac{4}{3}\right)}^5-{\left(\frac{2}{3}\right)}^5\right)-\frac{1}{3!\cdot 2^3\cdot 7}\left({\left(\frac{4}{3}\right)}^7-{\left(\frac{2}{3}\right)}^7\right)+\frac{1}{4!\cdot 2^4\cdot 9}\left({\left(\frac{4}{3}\right)}^9-{\left(\frac{2}{3}\right)}^9\right)-\dots \end{equation*}
    by integrating the power series
    \begin{equation*} e^{-\frac{1}{2}z^2}=1-\frac{z^2}{1!\cdot 2}+\frac{z^4}{2!\cdot 2^2}-\frac{z^6}{3!\cdot 2^3}+\frac{z^8}{4!\cdot 2^4}-\dots \end{equation*}
    term by term.
    🔗

    (a)

    Write this final answer in summation notation.
    🔗
    🔗

    (b)

    Redo this integral in another way.
    1. Write \(e^x=1+\frac{x^1}{1!}+\frac{x^2}{2!}+\frac{x^3}{3!}+\dots \) in summation notation.
      🔗
    2. Substitute \(x=-\frac{1}{2}z^2\) into your summation.
      🔗
    3. Use the result of the previous problem (assuming that it holds for infinite sums as well)
      🔗
    🔗
    🔗
    Did you get the same result? Which way seems easier?
    🔗
    🔗
    In part b, of the above problem, you should have obtained something like
    \begin{equation*} e^x=1+\sum^{\infty }_{n=1}{\frac{x^n}{n!}} \end{equation*}
    In many books you will see this written as
    \begin{equation*} e^x=\sum^{\infty }_{n=0}{\frac{x^n}{n!}}=\frac{x^0}{0!}+\frac{x^1}{1!}+\frac{x^2}{2!}+\frac{x^3}{3!}+\dots \end{equation*}
    🔗
    It is understood that \(0!=1\text{.}\) Not only does this work in such a pattern as above, but it also makes sense if you think of computing such a product on a computer. For example, to program a computer to compute say \(20!\text{,}\) one would initially define the product \(P=1\) and then successively multiply the product by \(n=1\text{,}\) then \(n=2\text{,}\) then \(n=3\text{,}\) etc. and stop this loop when \(n>20.\) For a computer to compute \(0!\text{,}\) it would start with an initial product of \(P=1\) and end before it looped since \(n=1>0\text{.}\) Go ahead and plug this into any calculator; you will get \(0!=1\text{.}\)
    🔗
    In a similar fashion, if you ever see a summation \(\sum^b_{n=a}{y_n} \)where \(b\lt a\text{,}\) this will automatically be \(0\text{.}\) The same reasoning applies. If one wanted to program a computer to compute say \(\sum^{100}_{n=1}{n}\text{,}\) one would start with a sum \(S=0\) and successively add \(n=1, 2, 3, \)etc. and stop when \(n\gt 100\text{.}\) To compute \(\sum^0_{n=1}{n}\text{,}\) the sum would be \(0\) and the loop would end before it started as \(1\gt0\text{.}\)
    🔗
    In the next section, we will express sums expanded out and in summation notation for a little while. Eventually, we will interchange between the two depending on our needs. We expect at that point that you can comfortably go from one notation to the other.
