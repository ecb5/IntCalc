    Section 7.1 Defining the Riemann Integral

    As we mentioned in the introduction, the desire for rigorously defining an integral in the \(19\)th century was motivated by two main issues: replacing infinitesimals with a more rigorous concept such as limits and understanding how to integrate more complex functions. We do want to emphasize that applying differentials (infinitesimals) for computing areas, volumes, arc length, work, kinetic energy, etc. as we did in Section XXX was and still is a useful technique and one should be willing to use such a powerful tool. But as with any powerful tool, there is always a chance to misuse it, and this is where the rigor comes in. For example, if
    \begin{equation*} f(x)=\frac{\abs{x}}{x}= \begin{cases} 1 \amp{} x\gt 0 \\ -1 \amp{} x\lt 0 \text{,}\end{cases} \end{equation*}
    then
    \begin{equation*} f^\prime{}(x)=n \begin{cases} 0 \amp{} \text{if }x\neq0,\\ \text{does not exist} \amp{} \text{if }x=0 \text{.}\end{cases} \end{equation*}
    🔗
    Intuitively, the fact \(f^\prime{}\) does not exist at a single point should not affect the value of the definite integral and in fact it does not, so intuitively \(\int^1_{x=-1}{f^\prime{}(x)}\dx{x}=0\text{.}\) However, if one blindly tried to use the Fundamental Theorem of Calculus, one would obtain
    \begin{equation*} \int^1_{x=-1}{f^\prime{}(x)}\dx{x}=f\left(1\right)-f\left(-1\right)=1-\left(-1\right)=2 \end{equation*}
    Clearly, not existing at a single point upset the Fundamental Theorem of Calculus. The integral must be studied more carefully.
    🔗
    As with nearly all new ideas, it is hard to attribute this to just one person. In the case of providing a rigorous definition of a definite integral, the names Sylvester François LaCroix (1765-1843), Siméon Denis Poisson (1781-1840), and Augustin Louis Cauchy (1789-1857) are part of this evolution. It was Georg Friedrich Bernhard Riemann (1826-1866) who coalesced these ideas into our modern definition and it is his name that gets attached to what we now refer to as the Riemann Integral.
    🔗
    As we mentioned in the previous chapter, the idea of using finite sums to approximate integrals predates all of the people mentioned with understanding that such approximations typically got better as the width of the subintervals was made smaller. This leads to the following definition of a Riemann integral of a function \(f(x)\) defined on \([a,b]\text{.}\) To restate what we had before, a partition \(P\) of the interval \([a,b]\) is a set of points \(\{x_0, x_1, x_2, \dots, x_n\}\) with
    \begin{equation*} a=x_0\lt{}x_1\lt{}x_2\lt{}\dots \lt{}x_n=b \end{equation*}
    and denote \(\Delta{}x_j=x_j-x_{j-1}\text{,}\) \(j=1, \dots, n\text{.}\) Since we will need the lengths of all of these subintervals to approach zero, we define the norm of the partition \(P\) by
    \begin{equation*} \norm{P}=\max_{1\le j\le n} \left(\Delta{} x_j\right)\text{.} \end{equation*}
    This way we can ensure that all the length of the subintervals approaches zero by making \(\left\|P\right\|\to 0\text{.}\)
    🔗
    If we let \(x^*_j\) denote any point in the subinterval \([x_{j-1},x_j]\) then we form the Riemann sum
    \begin{equation*} \sum^n_{j=1}f(x^*_j)\Delta{}x_j=f\left(x^*_1\right)\Delta{}x_1+f\left(x^*_2\right)\Delta{}x_2+f\left(x^*_3\right)\Delta{}x_3+\dots +f\left(x^*_n\right)\Delta{}x_n \end{equation*}
    🔗
    Here is a diagram of the situation.
    🔗
    We define the Riemann Integral as
    \begin{equation*} \int^b_{x=a}{f(x)\dx{x}}=\limit{\norm{P}}{0}{ \sum^n_{j=1}f(x^*_j)\Delta{ }x_j} \end{equation*}
    provide this limit exists and is the same for all choices of \(x^*_j\text{.}\) If this limit exists then we say that \(f\) is Riemann integrable (on \([a,b]\)).
    🔗
    This is quite a bit of terminology at once but remember that you were used to approximating integrals by Riemann sums before, now we are just taking the limit as the widths of all the rectangles approach zero. Of course, as with any limit, there is no guarantee that this limit exists. Consider for example the Dirichlet function we mentioned in the introduction to this Chapter.
    \begin{equation*} D(x)= \begin{cases} 1 \amp{} \text{if }x\text{ is rational} \\ 0 \amp{} \text{if }x\text{ is irrational} \text{.}\end{cases} \end{equation*}
    🔗

    Problem 7.1.0.2.

    For any partition \(P=\{x_0, x_1, \dots, x_n\}\) of \([0,1]\) show there is a Riemann sum whose value is 1 and a Riemann sum whose value is 0. How does this say that \(D\left(x\right)\) is not Riemann integrable?
    🔗
    🔗
    As a contrast, let’s go back to the “popcorn” function of Thomae.
    \begin{equation*} T\left(x\right)= \begin{cases}{} \frac{1}{q} \amp{} \text{if } x=\frac{p}{q} \text{ where }p,q \text{ are integers, }\\ \amp{} p,q\neq 0,\\ \amp{} \text{and this fraction is in lowest terms} \\\\ 0 \amp{} \text{if }x \text{ is irrational} \text{.}\end{cases} \end{equation*}
    🔗
    We will use our definition to show that \(\int^1_{x=0}{T\left(x\right)\\dx{x}{x}}=0\text{.}\) With this in mind, let \(\eps >0\) represent any positive real number. If we superimpose the line \(y=\frac{\eps }{2}\) on our graph of \(y=T\left(x\right), 0\le x \le 1\)
    🔗
    we notice that there are only finitely many values \(X_1, X_2, X_3, \dots, X_m\) with \(T(X_j)>\frac{\eps}{2}\text{.}\) Consider any partition \(P=\{x_0, x_1, x_2,\dots,\ x_n\}\) of \([0,1]\) with \(\norm{P}\lt{}\frac{\eps}{2m}\text{.}\) Now let’s look at any Riemann sum \(S=\sum^n_{j=1}{T(}x^*_j)\Delta{}x_j\) corresponding to this partition. Notice that if a subinterval \([x_{j-1}, x_j]\) doesn’t contain any \(X_k\text{,}\) then \(0\le T\left(x^*_j\right)\le \frac{\eps }{2}\) and so we have
    \begin{equation*} 0\le T\left(x^*_j\right)\Delta{}x_j\le \frac{\eps }{2}\Delta{}x_j \end{equation*}
    🔗
    So, the sum of these terms is bounded above by \(\frac{\eps}{2}\cdot 1\) (since the lengths of all the subintervals add up to the length of \([0,1]\)).
    🔗
    If the subinterval \([x_{j-1},x_j]\) does contain at least one of \(X_k\text{,}\) then we aren’t guaranteed that \(T(x^*_j)\) is less than \(\frac{\eps }{2}\text{,}\) but we do know that \(0\le T\left(x^*_j\right)\le 1\text{.}\) This says that the term \(T\left(x^*_j\right)\Delta{ }x_j\)satisfies
    \begin{equation*} 0\le T\left(x^*_j\right)\Delta{}x_j\lt{}1\cdot \frac{\eps }{2m} \end{equation*}
    🔗
    However, there are at most \(m\) such intervals. Thus, the entire Reimann sum satisfies the inequality
    \begin{equation*} 0\le S=\sum^n_{j=1}T(x^*_j)\Delta{}x_j\lt{}m\cdot 1\cdot \left(\frac{\eps }{2m}\right)+\left(\frac{\eps }{2}\right)\cdot 1=\eps \end{equation*}
    🔗

    Problem 7.1.0.3.

    Explain how this shows that
    \begin{equation*} \int^1_{x=0}T(x)\dx{x} \end{equation*}
    🔗
    🔗
    We have produced two examples of highly noncontinuous functions, one is Riemann integrable and the other is not. But what about the “ordinary” functions we were using in the practice section? It turns out that they are Riemann integrable as well. Specifically, we have the following theorem.
    🔗

    Theorem 7.1.0.4.

    Suppose \(f\left(x\right)\) is continuous on \([a,b]\text{,}\) then \(f(x)\) is Riemann integrable on \([a,b]\text{.}\)
    🔗
    🔗
    The proof of this relies on the makeup of the real number system and we will not prove it here. This main issue is knowing that there is actually something for the Riemann sums to converge to. If this sounds intriguing, you might want to consider becoming a math major and taking an introductory course in Real Analysis where such issues are addressed. Actually, we have a stronger theorem which we won’t prove either.
    🔗

    Theorem 7.1.0.5.

    Suppose \(f(x)\) is bounded on \([a,b]\) and has only a finite number of discontinuities. Then \(f\left(x\right)\) is Riemann integrable.
    🔗
    🔗
    In fact, this theorem is still not the strongest you can get. Notice that \(T(x)\) is discontinuous at every nonzero rational number. It is also continuous at every irrational number (which is not obvious). Even though this has an infinite number of discontinuities, it is still Riemann integrable. There are exact conditions for a function on a closed interval to be Riemann integrable, but we will not get into that here. It takes a lot of machinery that goes beyond what LaCroix, Poisson, Cauchy, and Riemann did. However, using the definition of a Riemann integral, one can prove all of the properties of definite integrals that we stated in Section XXX
