    Section 6.2 Representations of Polynomials

    Notice that when we write \(121_{10}\) as
    \begin{gather*} 121_{10} = 1+2\cdot10+1\cdot10^2 \end{gather*}
    the expression on the right has the form of a polynomial. That is, if we replace each instance of the base \(10\) with \(x\) we get the polynomial \(1+2\cdot x+1\cdot x^2\text{.}\) Polynomials can be thought of as numbers where the base is \(x\) (or that it is unspecified).
    🔗
    We will very soon find it very convenient to to be able to convert polynomials to different bases just like we converted numbers in the last section. Fortunately, the method we’ve just developed carries over unchanged.
    🔗

    Example 6.2.0.1.

    The polynomial \(p(x) = 1+2x+x^2\) is represented with \(x\) as the base. Convert it to the base \((x-1)\text{.}\)
    🔗
    As before, we want to find coefficients \(a_0, a_1,\) and \(a_2\) so that
    \begin{gather*} 1+2x+x^2 = a_0 + a_1(x-1) + a_2(x-1)^2. \end{gather*}
    Dividing both sides by \(x-1\) we get
    On the right:
    🔗
    \(a_1+a_2(x-1)\) with the remainder \(a_0\text{.}\)
    🔗
    On the left:
    🔗
    \(x+3\) with the remainder \(4\text{.}\) So \(a_0=4\) and \(x+3=a_1+a_2(x-1)\text{.}\)
    🔗
    Dividing again by \(x-1\) gives
    On the right:
    🔗
    \(a_2\) with the remainder \(a_1\text{.}\)
    🔗
    On the left:
    🔗
    \(1\) with the remainder \(4\text{.}\)
    🔗
    🔗
    Therefore
    \begin{gather*} 1+2x+x^2 = 4+4(x-1)+(x-1)^2. \end{gather*}
    🔗
    🔗

    Drill 6.2.0.2.

    Confirm the result in the previous example.
    🔗
    🔗
    For reasons that we will make clear later, we don’t normally refer to this re-representation of polynomials as a "change of base." Instead, when we convert from base \(x\) to base \(x-a\) for some \(a\) we say we are "expanding the polynomial about the number \(a\text{.}\)" When the base is \(x\) we say that the polynomial is expanded about the number \(0\text{.}\)
    🔗

    Aside: Comment.

    Even though that is really what it is.
    🔗
    A more substantial example is in order.
    🔗

    Example 6.2.0.3.

    Expand the polynomial \(p(x) = x^5+3x^4-15x^2+1\) about the number \(2\text{.}\)
    🔗
    As before we have
    \begin{gather*} x^5+3x^4-15x^2+1 = a_0+a_1(x-2)+a_2(x-2)^2+a_3(x-2)^3+a_4(x-2)^4+a_5(x-2)^5. \end{gather*}
    Dividing both sides by \(x-2\) gives
    On the right:
    🔗
    \(a_1+a_2(x-2)+a_3(x-2)^2+a_4(x-2)^3+a_5(x-2)^4\) with remainder \(a_0\text{.}\)
    🔗
    On the left:
    🔗
    \(x^4+5x^3+10x^2+5x+10\) with remainder \(21\text{.}\)
    🔗
    Thus \(a_0 = 21\) and
    \begin{gather*} x^4+5x^3+10x^2+5x+10 = a_1+a_2(x-2)+a_3(x-2)^2+a_4(x-2)^3+a_5(x-2)^4. \end{gather*}
    Dividing again we have
    On the right:
    🔗
    \(a_2+a_3(x-2)+a_4(x-2)^2+a_5(x-2)^3\) with remainder \(a_1\text{.}\)
    🔗
    On the left:
    🔗
    \(x^3+7x^2+24x+53\) with remainder \(116\text{.}\)
    🔗
    Thus \(a_1=116\) and
    \begin{gather*} x^3+7x^2+24x+53 = a_2+a_3(x-2)+a_4(x-2)^2+a_5(x-2)^3. \end{gather*}
    🔗
    Continuing in this fashion gives \(a_2= 137\) and
    \begin{gather*} x^2+9x+42 = a_3+a_4(x-2)+a_5(x-2)^2, \end{gather*}
    and then \(a_3=64\) and
    \begin{gather*} x+11 = a_4+a_5(x-2), \end{gather*}
    from which it is clear that \(a_5= 1\) and \(a_4=13\text{.}\)
    🔗
    Therefore
    \begin{gather*} x^5+3x^4-15x^2+1 = 21+116(x-2)+137(x-2)^2+64(x-2)^3+13(x-2)^4+(x-2)^5. \end{gather*}
    🔗
    🔗

    Drill 6.2.0.4.

    Verify the result in the previous example.
    🔗
    🔗
    If we expand the polynomial \(p(x) = x^3\) about the number \(1\) we get
    \begin{gather*} x^3 = a_0+a_1(x-1) +a_2(x-1)^2+a_3(x-1)^3. \end{gather*}
    Proceeding as before we find that \(a_0=1\) and \(a_2= 3\text{.}\) If, rather than completing the conversion we stop here it is reasonable to expect that the graphs of \(l(x) = a_0+a_1(x-1) = 1+3(x-1)\) and \(p(x) = x^3\) should be related, and indeed, when we graph both polynomials on the same set of axes we see the following.\\ \centerline{\includegraphics*[height=2in,width=2in]{../Figures/LinearTaylor}}
    🔗
    Hey! Wait a second! We’ve seen things like this before!
    🔗
    This appears to be the graph of \(p(x)=x^3\) and its tangent line at \(x=1\text{.}\) Is this just an artifact of this particular problem or is it generally true?
    🔗
    Clearly this is general. If we have an unspecified polynomial expanded about the number \(a\text{,}\) \(p(x) = a_0 + a_1(x-a) + a_2(x-a)^2 + \cdots + a_m(x-a)^n\) then clearly \(p(a) = a_1\) and \(\dfdx{p}{x}(a) = a_1\text{.}\) So it seems that in computing the coefficients \(a_0\) and \(a_1\) we have found the line tangent to \(p(x)\) at \(x=a\text{.}\) What do you suppose we will find when we compute \(a_2\text{?}\)
    🔗

    Drill 6.2.0.5.

    Find \(a_2\) graph \(x^3\) and \(a_0 + a_1(x-a) + a_2(x-a)^2\) on the same set of axes. What do you observe?
