Example 20.2.0.4. A Definite Integral.

This notation associated with integrals and antiderivatives very dense so it can be very confusing at first. A simple example will be helpful. Suppose we define
\begin{equation*} F(x)= \int_{t=2}^{x}3t^2\dx{t}\text{.} \end{equation*}
As we saw in n IVP (20.6) \(F(x) \) is the solution of the IVP
\begin{align*} \dfdx{F}{x}=3x^2, \amp{}\amp{}F(2)=0 \text{.} \end{align*}
One antiderivative of \(3x^2\) is \(\hat{F}(x) = x^3\text{,}\) but it is not the one we need since \({\hat{F}(2)\ne 0} \text{.}\) Clearly then
\begin{equation*} F(x)=\hat{F} (x)+C \text{.} \end{equation*}
We compute \(C\) as usual:
\begin{align*} F(2)=0 \amp{}=\hat{F} (2) +C\\ \amp{}=2^3+C, \text{ so }\\ C\amp{}=-8. \end{align*}
To compute the definite integral
\begin{equation*} \int_{2}^{5}3x^2\dx{x} \end{equation*}
we can use either \(F(x) \) or \(\hat{F}(x)\) since
\begin{align*} \int_{2}^{5}3x^2\dx{x} \amp{}= \eval{ \int_{2}^{5}3x^2\dx{x}}{x}{5} - \eval{ \int_{2}^{5}3x^2\dx{x}}{x}{2}\\ \amp{}= F(5)-F(2) \\ \amp{}= \left(F(5)-8\right)-\left(F(2) -8 \right)\\ \amp{}= \hat{F}(5)-\hat{F}(2). \end{align*}
