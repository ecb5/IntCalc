We Integrate Differentials, Not Functions.

If it seems remarkable that we can compute the sum \(\int\frac{\omega{}^2}{g}x\dx{x}\) by simply finding an antiderivative of \(\frac{\omega{}^2}{g}x\) that is because it really is quite astonishing. It is in fact our first encounter with what is known as the Fundamental Theorem of Calculus which we will spend considerable time on later in this text.
🔗
For now we will simply note that it is true and, at least in this simple context, rather apparent. But before we continue a clear distinction is necessary because antidifferentiation and integration are not the same thing. The situation is analogous to the relationship between addition and multiplication. We know that we can sometimes use multiplication to shorten a long addition:
\begin{align*} 3\times{23}=3+3\amp{}+3+3+3+3+3+3+3+3\\ \amp{} +3+3+3+3+3+3+3+3+3+3+3+3+3\text{.} \end{align*}
But this does not mean the addition and multiplication are the same thing.
🔗
Similarly, to antidifferentiate means to find an antiderivative of a function, whereas to integrate means to sum up a set of differentials like \(\frac{\omega }{g}x\dx{x}\text{.}\)
🔗
Antidifferentiation and integration are different (though related) operations just as addition and multiplication are. But unfortunately antidifferentiation and integration are both represented by the single symbol
\begin{equation*} \int f(x) \dx{x} \end{equation*}
which can be very confusing for the beginner. Much of the time the distinction will be unimportant to us because the actual computations we will need do are the same regardless of how we think about them. Because of this it is easy to lose sight of the fact that the integral symbol is used to represent two distinct ideas. But when we are using the integral as a problem solving tool the distinction will be important. For some problems it is easier to think of antidifferentiation. For others it is easier to think of summation.
🔗
To make matters worse it is customary to use the word integration to refer to both. Thus we have given Chapter 19 the customary title “Integration Techniques” when (in the opinion of the authors) it really should be called “Antidifferentiation Techniques.”
🔗
Starting in the next section we will focus our attention on interpreting an integral as an antiderivative. We will return to the summation interpretation in Section 20.2.
