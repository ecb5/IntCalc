Example 19.3.0.4. Population Dynamics: A Non–Separable Differential Equation.

Of course it is very unlikely that any predator will harvest the algae at a constant rate twenty-four hours a day. Most predators will be more active during the daylight hours than they are at night, so we can improve our model by inserting a periodic term which reflects that fact. The function \(\cos\left(t\right)\) is convenient so it seems that the differential equation in our model might be
\begin{equation*} \dfdx{y}{t} = Ky - \cos(t) \end{equation*}
but this doesn’t quite make sense physically because predation can only decrease the rate of growth. But any time when \(\cos\left(t\right)\lt{0}\) the presence of our predator will increase the growth rate of the algae population.
🔗
We need a periodic function which is always non-negative. There are many available, but for demonstration purposes we want to keep this as simple as possible so we’ll use \(1-\cos\left(t\right)\text{.}\)
🔗
Assuming we start with \(20\) kilograms of algae in the pond a reasonable model for algae growth is thus the IVP
\begin{align*} \dfdx{y}{t} = Ky - \left(1-\cos(t)\right),\amp{}\amp{} y(0)=20\text{.} \end{align*}
We will soon see that it is more convenient to rearrange this IVP slightly as
\begin{align} \dfdx{y}{t} - Ky = - \left(1-\cos(t)\right),\amp{}\amp{} y(0)=20.\tag{19.64} \end{align}
🔗
Alas, the differential equation part of IVP (19.64) is not separable but since we generated it by slightly tweaking equation (19.61) whose solution
\begin{equation} y(t)=Ae^{Kt}\tag{19.65} \end{equation}
it seems reasonable to suppose that we can find the solution of IVP (19.64) by slightly tweaking the solution of IVP (19.61).
🔗

Aside: Mathematical Terminology.

To “tweak” means to make a slight change so it is an appropriate word to use here despite being very informal. In a more formal setting we say that we perturb IVP (19.61) to get IVP (19.64), or that IVP (19.64) is a perturbation of IVP (19.61).
🔗
Observe that \(y(t)=Ae^{Kt}\) is the product of the constant \(A\) and the function \(e^{Kt}\text{.}\) Since IVP (19.64) is a slightly more complex problem than IVP (19.61) we’ll need a slightly more complex product, so we’ll guess that our solution has the form
\begin{equation*} \bar{y}(t)=A(t)\cdot e^{Kt} \end{equation*}
where \(A(t)\) is a differentiable function rather than a constant.
🔗
This “trick” of solving a “nearby” simpler problem and then upgrading the constant term to a function is effective in a variety of situations so it has been elevated to the status of “technique.” Since we are allowing the parameter \(A\) to vary the technique has been named Variation of Parameters. A detailed description of the technique is beyond the scope of this text. However, later in your education, you may well find yourself in a course called Ordinary Differential Equations where you will see it again.
🔗
The problem is now to find \(A(t)\text{.}\)
