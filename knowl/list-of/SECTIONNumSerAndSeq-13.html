Definition 2.2.0.3. Convergence to the Real Number.

We say that the sequence \(\left(a_n\right)\) converges to the real number \(a\) provided that for every \(\epsilon >0\text{,}\) there is a real number \(B\) with the property that
\begin{gather*} \left|a_n-a\right|\lt{}\eps \end{gather*}
whenever \(n\gt{}B\text{.}\) In this case, we write
\begin{gather*} \limit{n}{\infty{}}{a_n}=a \end{gather*}
or when we are being lazy, we write \(a_n\to a\text{.}\)
