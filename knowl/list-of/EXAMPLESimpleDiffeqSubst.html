Example 19.1.1.2.

Suppose we want to find the most general solution of
\begin{equation} \frac{\dx{y}}{\dx{x}}=\left(1+x\right)y.\tag{19.1} \end{equation}
This is a separable equation so we separate the variables resulting in
\begin{equation*} \frac{1}{y}\dx{y}=(1+x) \dx{x}. \end{equation*}
Integrating both sides we have
\begin{equation} \int\frac{1}{y}\dx{y}=\int 1+x \dx{x}\tag{19.2} \end{equation}
which we can solve using Table 18.1.0.4.
