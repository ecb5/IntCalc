Example 20.3.0.6.

All of the techniques we developed in Chapter 19 work just as well for definite integrals as for indefinite integrals, with the extra step of evaluating the integral at each limit of integration, and computing the difference.
🔗
We also need to make sure that the limits of integration refer to the integration variable. For example consider the integral
\begin{equation*} \int_{x=2}^3{xe^{x^2}\dx{x}}\text{.} \end{equation*}
If we make the substitution \(u=x^2\text{,}\) then \(\dx{u} =2x\dx{x} \text{,}\) and so
\begin{equation*} \int_{x=2}^3xe^{x^2}\dx{x} =\frac12 \int_{x=2}^3e^u\dx{u} \end{equation*}
but notice that now the index variable is \(x\) but the function variable is \(u\text{.}\) But we need them to match.
🔗
At this point, we have two options.
  1. We can integrate and then change the integraton variable back to \(x\text{.}\)
    🔗
  2. We can convert the index variable to \(u\text{.}\)
    🔗
We’ll show both.
🔗
The first approach is straightforward. We have
\begin{equation*} \frac12 \int_{x=2}^3e^u\dx{u} =\ftceval{\frac12e^u}{x}{2}{3}= \ftceval{\frac12e^{x^2}}{x}{2}{3}=\frac{1}{2}\left(e^9-e^4\right) \end{equation*}
🔗
For the second approach notice that when \(x=2\text{,}\) \(u = 4\) and when \(y = 3\text{,}\) \(u = 9\text{,}\) so that
\begin{equation*} \frac12 \int_{x=2}^3e^u\dx{u} =\ftceval{\frac12e^u}{u}{4}{9}= \ftceval{\frac12e^u}{u}{4}{9}=\frac{1}{2}\left(e^9-e^4\right){} \end{equation*}
🔗
It doesn’t really matter which procedure you choose. You’ll end up doing the same computations either way. We suggest you choose one and use it exclusively, at least at first.
