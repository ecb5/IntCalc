Example 19.2.3.3.

Next consider the rational expression \(\frac{1}{(x-1)^2(x+2)^2}\text{.}\) Proceeding as before we search for constants \(A\text{,}\) \(B\text{,}\) \(C\text{,}\) and \(D\) such that
\begin{gather*} \frac{1}{(x-1)^2(x+2)^2}= \frac{A(x-1)+B}{(x-1)^2}+\frac{C(x-1)+D}{(x+2)^2} \end{gather*}
or
\begin{gather*} \frac{1}{(x-1)^2(x+2)^2}= \frac{A}{x-1}+\frac{B}{(x-1)^2}+\frac{C}{x+2}+\frac{D}{(x+2)^2}. \end{gather*}
By Heaviside’s Method we can see that
\begin{align} B\amp{}=\eval{ \frac{1}{(\text{covered})(x+2)^2}}{x}{1}=\frac{1}{9}\tag{19.48} \end{align}
and
\begin{align} D\amp{}=\eval{\frac{1}{(x-1)^2(\text{covered})}}{x}{-2}=\frac{1}{9}.\tag{19.49} \end{align}
And so we have
\begin{gather*} \end{gather*}
or
\begin{gather} \frac{1}{(x-1)^2(x+2)^2}-\frac{\frac{1}{9}}{(x-1)^2}-+\frac{\frac{1}{9}}{(x+2)^2}= \frac{A}{x-1}+\frac{C}{x+2}\tag{19.50} \end{gather}
🔗
At this point we are in a situation similar to that of equation (19.46), except that this time we have two constants to find. If we try to proceed as we did there we see that
\begin{align*} \frac{1}{(x-1)(x+2)}-\frac{\frac{1}{9}(x+2)}{(x-1)}-\frac{\frac{1}{9}(x-1)}{(x+2)}\amp{}= A(x+2)+C(x-1)\\ \amp{}=(A+C)x+(2A-C). \end{align*}
The obvious next step is to multiply out the left side of the equation — we are guaranteed to get a linear polynomial — and compare the coefficients. But that is the method we rejected in favor of Heaviside’s Method back in Subsection 19.2.1 because it was too complicated. We’d really like to find a simpler method.
🔗
Take another look at equation (19.50), especially the right side. If we were to start with a rational of the form \(\frac{P(x)}{(x-1)(x+2)}\) (where \(P(x)\) is a polynomial we will determine shortly) and try to decompose it we get
\begin{gather} \frac{P(x)}{(x-1)(x+2)}=\frac{A}{x-1}+\frac{C}{x+2}.\tag{19.51} \end{gather}
Thus we have
\begin{gather*} \frac{1}{(x-1)^2(x+2)^2}-\frac{\frac{1}{9}}{(x-1)^2}-\frac{\frac{1}{9}}{(x+2)^2}=\frac{P(x)}{(x-1)(x+2)}. \end{gather*}
Though it probably isn’t clear how, this is very helpful because it will allow us to find \(P(x)\) very efficiently. Clearing the fractions we see that
\begin{gather*} \underbrace{\frac{1}{(x-1)(x+2)}}_{=R_1}-\underbrace{\frac{\frac{1}{9}(x+2)}{x-1}}_{=R_2}-\underbrace{\frac{\frac{1}{9}(x-1)}{x+2}}_{=R_3}=P(x). \end{gather*}
This is similar to what we saw in equation (19.47) except that this time we are guaranteed that the sum of the terms on the left will reduce down to some polynomial. Do you see how to find the polynomial without doing all of that algebra? Think about it for a bit before going on.
🔗
We will consider each of the expressions \(R_1\text{,}\) \(R_2\text{,}\) and \(R_3\) separately.
\(R_1=\frac{1}{(x-1)(x+2)}\)
🔗
This expression is in what we will call “lowest terms” for purposes of this discussion. What we mean is that there is no algebraic operation we can perform on this expression — without changing its value — that will yield a polynomial. Thus we can ignore it.
🔗
\(R_2=\frac{\frac{1}{9}(x+2)}{x-1}\)
🔗
Next consider \(R_2=\frac{\frac{1}{9}(x+2)}{x-1}\text{.}\) If we perform the indicated division we get
\begin{align*} \amp{}\frac{\frac{1}{9}(x+2)}{x-1}\\ \amp{}\ \ \ \ =\frac{1}{9}+\text{some rational function in "lowest terms."} \end{align*}
We have not bothered to write down the rational function that appears from the division because, since it is in “lowest terms” we can ignore it, just like \(R_1\)
🔗
\(R_3=\frac{\frac{1}{9}(x-1)}{x+2}\)
🔗
Just like \(R_2\) this division will result in
\begin{align*} \amp{}\frac{\frac{1}{9}(x-1)}{x+2}\\ \amp{}\ \ \ \ =\frac{1}{9}+\text{some rational function in "lowest terms."} \end{align*}
where the function in “lowest terms” is not necessarily the same one we had before, but again since it will not yield a polynomial we can ignore it.
🔗
🔗
After ignoring the irrelevant terms identified above we have
\begin{align*} P(x) \amp{}= \CancelTo{0}{R_1}- \CancelTo{\frac{1}{9}}{\ R_2}-\CancelTo{\frac{1}{9}}{\ R_3} = -\frac{2}{9}, \end{align*}
which is a polynomial of degree \(0\text{.}\)
🔗
Combining this with equation (19.51) we have
\begin{gather*} \frac{-\frac{2}{9}}{(x-1)(x+2)}=\frac{A}{x-1}+\frac{C}{x+2} \end{gather*}
and we can again use Heaviside’s Method to determine that
\begin{align} A\amp{}=\eval{\frac{-\frac{2}{9}}{(\text{covered})(x+2)}}{x}{1}=-\frac{2}{27}\tag{19.52} \end{align}
and
\begin{align} C\amp{}=\eval{\frac{-\frac{2}{9}}{(x-1)(\text{covered})}}{x}{-2}=\frac{2}{27}.\tag{19.53} \end{align}
Combining equations (19.48), (19.49), (19.52), and (19.53) we have
\begin{gather} \frac{1}{(x-1)^2(x+2)^2}= \frac{-\frac{2}{27}}{x-1}+\frac{\frac{1}{9}}{(x-1)^2}+\frac{\frac{2}{27}}{x+2}+\frac{\frac{1}{9}}{(x+2)^2}.\tag{19.54} \end{gather}
which we can integrate.
