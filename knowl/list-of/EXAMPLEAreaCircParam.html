Example 26.1.0.1. The Area of a Circle With Radius \(\boldsymbol{= a}\).

A circle with radius \(a\) can be parametrized by:
\begin{equation*} P(\theta)= \ParamEqTwo {x(\theta)} {y(\theta)}= \ParamEqTwo {a\cos(\theta))} {a\sin(\theta)} \end{equation*}
where \(0\le{}\theta{}\lt{}2\pi{}\) so the area of the circle is given by
\begin{gather*} \int{}y\dx{x} = \int{}\underbrace{a\sin\left(\theta{}\right)}_{y(\theta{})}\underbrace{\left(-a\sin(\theta)\right) \dx{\theta}}_{\dx{x}} = a^2\int{}\sin^2(\theta{})\dx{\theta{}}, \end{gather*}
once we find appropriate indices but unfortunately things will go badly if we try to use the mental image of summing rectangles.
🔗
At first its seems as if that would be relatively simple: Simply integrate from right to left as usual. This is the essential idea but the computation is not as straight–forward as that. Before we are done we will have to re–think our understanding of what an integral actually is. We’ll come to that in due time. For now we will proceed slowly to see what goes wrong.
🔗
Naively integrating from right–to–left gives
\begin{gather*} a^2\int_{x=-a}^a\sin^2(\theta)\dx{\theta } \end{gather*}
which has several problems. First, the integration variable is \(\theta\) not \(x\text{,}\) so it is not entirely clear what summing \(\sin^2(\theta{})\dx{\theta{}}\) from \(x=-a\) to \(x=a\) would actually compute. To be sure we’ve seen integrals where the indices did not refer directly to the integration variable before, mostly when we were doing an integration by substitution. But in that situation we had forced this unhappy state of affairs with our substitution and we always arranged for the indices and the integration variable to match before computing the integral. In this situation inconsistency of the variables came from the problem itself, not from anything we introduced. But it is the same difficulty and we can should be able to resolve it in the same fashion. We need to either re–express \(x\) in terms of \(\theta{}\) or vice versa. Finding \(\theta\) in terms of \(x\) will actually work (sort of), but since we want to illustrate what can go wrong we will go with the other choice.
🔗
We need to find \(\theta{}\) such that \(x(\theta{}) = a\cos(\theta{}) = -a\text{,}\) which says that \(\cos(\theta{})=-1\) or \(\theta{}=\pi{}\text{.}\) Similarly when \(x(\theta{})=a\text{,}\) \(\theta{}=0\) and it appears that we need to compute
\begin{gather*} a^2\int_{\theta =\pi{}}^0\sin^2(\theta )\dx{\theta }. \end{gather*}
But if we compute this integral we’ll get zero, which is obviously wrong. Try it and see.
