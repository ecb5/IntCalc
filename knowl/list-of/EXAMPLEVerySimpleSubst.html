Example 19.1.1.1.

Recall that to differentiate an expression such as \(y=\sin (5x)\text{,}\) we used the substitution \(u=5x\) so that we had \(\dx{y}=\cos (u) \dx{u}=\cos (5x)(5\dx{x})\text{.}\) We can use the same substitution to reverse the process.
🔗
Suppose we want to evaluate the integral \(\int\cos\left(5x\right)\dx{x}\text{.}\) We make the substitution \(u=5x\) so that \(\dx{u}=5\dx{x}\text{.}\) Substituting these into our integral gives
\begin{align*} \int \cos(5x) \dx{x} \amp{} = \int\cos\left(u\right) \frac{1}{5}\dx{u}\\ \amp{} = \frac15\sin(u)+C \\ \amp{} = \frac15\sin(5x)+C \text{.} \end{align*}
