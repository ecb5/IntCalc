Example 2.2.3.5.

Our solution to the problem in Example 2.2.3.3 probably appeared to be fairly complex but that is only because we needed to carefully explain our reasoning at each step. Since we don’t need to do that anymore this example will probably seem much simpler, even though it is actually a little bit more complex.
🔗
Consider the function
\begin{gather*} R(x) = \frac{-2x^4+2x^3+12x^2+46x+11}{(x+1)^3(x-2)^2}. \end{gather*}
Its decomposition has the form
\begin{align*} \amp{}\frac{-2x^4-19x^3+45x^2+247x+297}{(x+1)^3(x-2)^2}\\ \amp{}\ \ \ = \frac{A}{x-1}+\frac{B}{(x-1)^2}+\frac{C}{(x-1)^3}+\frac{D}{x-2}+\frac{E}{(x-2)^2} \end{align*}
