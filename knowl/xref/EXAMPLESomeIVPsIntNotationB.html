Task 20.2.1.6.b.
Of course we could have solved the IVP in part (a) by guessing just like we did before. Let’s look at an example that we can’t solve by guessing. Let’s solve the IVP
\begin{gather*} \dfdx{y}{x}= \pi e^x\sin(\pi{}e^x), \text{ } y(0)=7. \end{gather*}
Separating the variables we see that
\begin{align*} y(x) =\int_{t=0}^x \pi{}e^x\sin(\pi{}e^x)\dx{x}, \amp{}\amp{} y(0)=0. \end{align*}
🔗
First we need an antiderivative of \(\pi e^x\sin(\pi{}e^x)\text{.}\) Using the techniques we learned in Section 19.1 we see that one antiderivative is \(y(x)=-\cos(\pi e^x) \text{.}\) As usual this is not the antiderivative we seek. So we set \(y(0)=-\pi\cos(\pi{}e^0)+C\) and try to find the value of \(C\) that works. This is clearly
\begin{equation*} y(x)=-\cos (\pi e^x)+6\text{.} \end{equation*}
